# Bamboo Music Player — 最终实施方案（Rust / Windows x64）

## 0. 已确认的决策
- **Rust + egui/eframe + wgpu（DX12）**：纯原生桌面程序，无 WebView；GPU 合成 UI，可选低功耗/高性能 GPU。
- 主窗口保留 **Windows 原生标题栏**（DWM 深色/圆角），内容区现代自绘：侧边导航、圆角卡片、渐变/毛玻璃、克制动效。
- **歌词双系统**：主界面完整歌词面板 + 可选常驻右侧歌词栏；独立桌面歌词窗口；两者样式、字体、颜色、背景、行数、动画均可深度自定义；另有全屏歌词页与歌词编辑器。
- **音源可配置**：默认仅 Bamboo local（`http://127.0.0.1/musicnew/apis/local`）；酷我(A)/网易(B)/QQ(D) 为预设，基址、端点路径覆盖、请求头/Cookie、密钥、品质、开关均可改。
- `.mp3list`：`#SEARCH#<目录>` 递归扫描；普通行=文件/URL；在线曲目写 `#BAMBOO#<源>|<ID>|<标题>|<歌手>`（Bamboo 走 API，URL 直连）。
- **托盘菜单** + **退出缓存**（完整队列、当前索引、播放位置、随机顺序、循环、音量、页面、窗口/桌面歌词位置、列表滚动位置；定期原子保存，异常退出可恢复）。
- 本轮选中的增强全部纳入，且**均可在设置中单独启用/关闭**；手机遥控、标签编辑列为低优先级后续。

## 1. 功能全景

### 1.1 核心需求
本地/在线播放（mp3/ogg/wav/flac/m4a/aac/opus）、播放控制、进度/音量、随机排序、循环、`.mp3list` 导入导出与去重、`#SEARCH#` 目录扫描、搜索/筛选、本地曲库、Bamboo 在线搜索/专辑/歌手、封面、LRC/SRT（GBK/UTF-8 自动或强制）、主界面歌词、桌面歌词、完整设置、托盘、退出缓存、捕获保护、单实例、拖拽导入。

### 1.2 本轮增强（全部带开关）
**播放/音质**
- 交叉淡化 0–12 秒 + 无缝播放（双解码甲板混音）。
- ReplayGain 响度均衡（标签优先，可后台分析）+ 10 段 EQ（预设/自定义/前置放大/限幅）。
- 变速 0.5–2.0x（默认保持音调，可改简单变速）+ A-B 区间循环。
- 睡眠定时（分钟/当前曲目结束/队列结束，淡出停止）+ 网络电台（ICY/HTTP 流、基础 HLS、电台管理）。

**曲库/歌词**
- 智能歌单（标签/年份/播放次数/最近添加等规则，自动更新）+ 收藏、1–5 星评分、播放统计（时长/次数/榜单）。
- 重复检测（规范化元数据 + 可选 BLAKE3 哈希）与清理（仅移出曲库/移入回收站），缺失文件定位与批量重定位。
- 歌词编辑器：打轴/微调/双语编辑/预览，导出 LRC/SRT（UTF-8/GBK），生成歌词分享图。
- 未选：本地歌曲自动在线匹配歌词/封面，暂不纳入（可后续加）。

**在线/离线**
- 在线下载：音频+封面+歌词+标签写入，命名模板、目录规则、队列/进度/暂停/重试、冲突策略、加入曲库。
- 播放缓存 + 离线模式：边听边缓存、容量上限/清理、断网播放已缓存曲目。
- 发现页：随机漫游、专辑/歌手浏览；粘贴 Bamboo 分享链接/`#musicid=`/裸 ID 直接打开。
- 高级网络：每源自定义请求头/Cookie、HTTP 代理（系统/手动）、自签名 HTTPS 信任开关、超时/重试/退避、User-Agent。

**界面/系统**
- 迷你播放器（置顶小窗）+ 沉浸式全屏歌词（封面/歌词/可视化，多显示器）。
- GPU 音频可视化（频谱/波形/圆环，30fps 上限，自动隐藏，默认关）。
- 切歌通知（封面，操作尽力而为）、任务栏跳转列表、开机启动、`.mp3list`/音频文件关联（按用户注册，不强制抢占默认）。
- Ctrl+K 命令面板（歌曲/歌单/命令/设置模糊搜索）、中英双语界面、AccessKit 屏幕阅读器与键盘导航、高对比/减少动效。

### 1.3 低优先级后续（核心稳定后）
- 手机遥控：局域网内置 HTTP + 移动端页面 + PIN/二维码配对（仅传输/音量/队列）。
- 标签编辑：批量编辑标题/歌手/专辑/音轨/年份/流派/封面/歌词，写入前备份，支持 mp3/flac/m4a/ogg。
- 其他可选：MV 视频、Last.fm/Discord 状态、远程投送（未选，暂不纳入）。

## 4. 关键设计

### 4.1 GPU 渲染与低功耗
- wgpu/DX12 GPU 合成；主窗口默认不透明，桌面歌词/迷你窗按需透明；DWM 深色标题栏、圆角、可选 Mica。
- GPU 偏好可选节能/高性能；背景模式：静态预模糊（默认）/GPU 多级模糊/流动渐变/纯色渐变/自定义图片/Mica。
- 帧调度：静止 0 帧；播放且可见 ~20fps；歌词/可视化动画短时 60fps；桌面歌词 30fps；隐藏停止计时器；全部基于 `request_repaint_after`。
- 纹理分级（列表 128/页面 512/背景 64）LRU；歌词布局 galley 缓存；逐字高亮裁剪叠加；管线预热避免首帧卡顿。
- 可视化：音频回调写入无锁环形缓冲，UI 30fps 做 FFT，GPU 绘制；仅可见且启用时运行。

### 4.2 音频引擎
- 双甲板结构（A/B）便于无缝/交叉淡化；每甲板解码→重采样→环形缓冲，回调混音。
- 精确 seek、音量平滑、欠载上报；暂停/空闲暂停输出流省电。
- 在线流：`type=url` text/plain → Range(206)；不支持 Range 回退临时文件；403 自动刷新续播。
- ReplayGain 标签优先，缺失可后台 ebur128 分析；EQ 10 段 biquad + 前置放大 + 限幅；变速默认保持音调；A-B 循环。
- 格式：mp3/ogg/wav/flac/m4a/aac/opus；电台 ICY/HLS 无 seek，断线重连。
- 位置每 5 秒及退出写入 Session；睡眠定时淡出停止。

### 4.3 歌词系统
- LRC：多时间戳、`[offset:]`、元数据、`<mm:ss.xx>` 逐字、双语同时间戳合并、坏行容错。
- SRT：序号/时间轴/多行、清理 HTML/`{\an8}`、双语、结束时间精确高亮。
- 编码：默认自动（BOM→UTF-8 校验→chardetng→GB18030）；可强制 UTF-8/GBK/GB18030/UTF-16LE/BE/Big5；设置页预览重载。
- 发现：同名 `.lrc/.srt` → 内嵌标签 → 同目录模糊匹配 → Bamboo `info.lrc` → 无。
- 主界面：完整滚动面板 + 可选常驻右侧栏 + 窄窗三行；当前行高亮/居中/逐字/翻译/点击跳转/滚轮脱离跟随/±0.5s 偏移/来源提示。
- 桌面歌词：透明置顶无边框、拖动/锁定/穿透、1–5 行+翻译+底部当前播放、预设（深色半透明/白底红蓝/纯文字/自定义）、独立捕获保护、多显示器/位置记忆/DPI/越界回夹。
- 编辑器：载入/新建、空格打轴、行编辑/增删/排序、双语、偏移、预览、保存 UTF-8/GBK、导出 SRT、分享图；自动备份。
- 缓存：解析结果内存/磁盘缓存；下首歌词预取可关；查找二分；布局缓存。

### 4.4 歌单、队列与退出缓存
- `Track`：Local/Url/Bamboo{source,id}/Radio；去重键：规范化路径/URL/源+ID/电台 URL。
- 随机：Fisher-Yates 全排列（当前曲固定），显示即随机序；关闭恢复原序；跨轮重新洗牌。
- 循环关/列表/单曲；历史栈；下一首播放/加入队列。
- `.mp3list`：编码识别、`#SEARCH#` 递归（扩展名可配）、`#BAMBOO#` 扩展行、URL、注释、相对路径、导入去重、缺失标灰、导出 UTF-8（可选 BOM）、原子写入；兼容 M3U/M3U8。
- 命名歌单管理；退出缓存 `session.json` 原子保存并每 5 秒节流；启动恢复队列+索引+位置（默认暂停，可自动播放）+随机序/循环/音量/页面/窗口/歌词位置/滚动位置。

### 4.5 在线、下载、缓存与网络
- 音源：local/A/B/D + 自定义基址/端点路径/前缀/密钥/品质；默认仅 local；`type=url` 纯文本、相对地址按站点根、`total` 哨兵、HTTP 200 错误 JSON 统一校验。
- 搜索/建议/专辑/歌单/歌手/信息/歌词/封面；多源筛选、分页、来源徽标、音质警告。
- 下载：队列并发 1–3、暂停/恢复/重试、进度/速度、命名模板（歌手/专辑/标题/音轨）、目录规则、冲突策略、封面/歌词/标签写入、完成后加入曲库。
- 缓存：流式缓存（源+ID+品质）、LRU 容量上限/清理、离线模式断网播放缓存；与下载目录分离。
- 发现：本地/在线随机、专辑/歌手浏览、分享链接/ID 解析打开。
- 网络：每源请求头/Cookie、代理、自签名 TLS 开关（警示）、超时/重试/退避、UA；测试连接。

### 4.6 曲库、智能歌单与查重
- 增量扫描（mtime+size）、lofty 标签/封面、SQLite 曲目/收藏/评分/播放次数/最近播放/歌词路径/单曲偏移。
- 歌曲/专辑/歌手/文件夹视图，虚拟列表、搜索排序、播放全部/加入队列。
- 智能歌单规则（字段/操作符/值，AND/OR，排序/上限），内置最近添加/最近播放/最常播放/从未播放/收藏/无损/长曲。
- 统计：总时长、次数、Top 歌手/专辑/歌曲；播放完成阈值计数，跳过不计。
- 查重：元数据（标题+歌手+时长±2s）或哈希（首尾块+大小，可选全量）；仅移出曲库/回收站；缺失定位与按文件名+大小批量重定位，同步更新队列/歌单/Session。

### 4.7 Windows 集成与托盘
- 托盘：显示/隐藏、播放/暂停、上一首/下一首、桌面歌词、锁定/穿透、音量、随机、循环、退出；提示"歌名 - 歌手"；左键切换窗口；关闭到托盘可配。
- SMTC 媒体浮层/媒体键/蓝牙按键；全部快捷键可录制、冲突检测。
- 捕获保护：主窗口/桌面歌词/迷你窗分别可设 `WDA_EXCLUDEFROMCAPTURE`，不支持时提示。
- 通知（封面、点击聚焦，操作尽力而为）、跳转列表、开机启动（HKCU Run）、按用户注册文件关联（不强制默认）、单实例 WM_COPYDATA、命令行/拖拽打开。
- 迷你播放器、全屏歌词、桌面歌词均独立 viewport，共享引擎与状态。

### 4.8 设置与开关
外观（主题/强调色/背景模式/模糊/透明度/字体/字号/圆角/动效/语言）、播放（设备/音量/交叉淡化/无缝/ReplayGain/EQ/变速/A-B/seek 步长）、歌词（编码/查找/样式/偏移/翻译/逐字/常驻栏/编辑器）、桌面歌词（全部样式/行数/锁定/穿透/捕获/显示器）、在线音源（基址/路径/密钥/头/Cookie/代理/TLS/品质/开关/测试）、下载与缓存（目录/模板/并发/上限/清理/离线）、曲库（目录/扫描/智能歌单/统计/查重/缺失）、窗口（托盘/捕获/位置）、快捷键、通知/跳转/开机/关联、功能开关总表、关于/诊断。
- 配置 `%APPDATA%\BambooMusicPlayer\settings.json`；`portable.txt` 用程序目录；防抖、原子替换、版本迁移、导入导出、重置。
- **所有增强的功能开关集中在一页**，默认：无缝开、交叉淡化关、ReplayGain/EQ/变速/A-B/可视化/开机启动关、缓存开（默认上限 1GB）、通知开（仅后台）、跳转列表开、中英文可切、遥控/标签编辑后续。

## 6. 测试与风险
- 单元：LRC/SRT（多时间戳/偏移/逐字/双语）、编码、`.mp3list`/M3U、去重、随机/循环、智能歌单规则、配置迁移、Bamboo 响应/URL（哨兵/相对/错误 JSON）、命名模板。
- 解码：生成 WAV 验证探测/seek/重采样/无缝；不依赖音频设备。
- 手工：各格式播放/seek/淡化/变速/EQ/RG、万级列表、中文输入、歌词全流程、桌面/全屏/迷你、托盘、捕获、退出恢复、下载/缓存/离线、通知/跳转/关联、双语/键盘/朗读、可视化。
- 性能：空闲 CPU/GPU≈0；播放 UI 低占用；无持续掉帧；缓存可控。
- 风险回退：wgpu 透明/驱动异常→glow 或独立 winit 窗；DX12 失败→Vulkan/GL；GPU 特效卡顿→自动静态模糊；在线源失效→提示/可禁用；不支持 Range→临时文件；HLS 复杂流→提示不支持；WinRT 通知/关联受限→提示并保留其他入口；大字号字体图集→系统字体/有限档位/缓存；无 MSVC→GNU 工具链。
