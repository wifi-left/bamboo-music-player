# Bamboo Music Player

> **AI 生成提示**

Windows 原生音乐播放器。主窗口使用 Win32 + GDI 自绘，Direct2D 仅用于桌面歌词 /
迷你播放器等覆盖层；业务核心与 UI 完全分离（`Snapshot` / `Command`）。

## 目录

- 根目录 — 原生 UI crate（`bamboo-music-player`，Rust 2024 + Win32 + GDI/D2D）
  - 构建/运行：`cargo run`；发布构建：`cargo build --release`
    （产物 `target\release\bamboo-music-player.exe`，windows 子系统、无控制台）
  - 自检（创建窗口、绘制一帧后自动退出）：`cargo run -- --self-test`
  - 基准（1 万首合成队列）：`cargo run -- --bench 5`
  - 打开音频/目录：`cargo run -- "F:\music"`，或直接把文件/文件夹拖进窗口
  - 迁移方案： [`docs/WIN32_UI_PLAN.md`](docs/WIN32_UI_PLAN.md)
  - 原生 UI 经验与踩坑：[`docs/NATIVE_UI_EXPERIENCE.md`](docs/NATIVE_UI_EXPERIENCE.md)

## 当前状态（2026-11-11）

业务核心迁移与原生外壳均已完成，debug / release 都可构建运行：

- **`src/core/` 是唯一的 UI 无关核心**（audio / library / lyrics / config /
  playlist / api / download / radio / util / platform / overlays / tray），
  不引用 egui/eframe/winit。
  - `core::app::AppCore` 负责播放编排、队列、歌词加载、封面解码、设置/会话持久化；
    UI 只读 `Snapshot`、只发 `Command`。
  - 真实队列与真实音频引擎：播放/暂停、上一首/下一首、拖动/键盘 seek、
    音量/静音、随机/循环、会话恢复、退出/周期自动保存。
  - 支持命令行传入文件/目录与 `WM_DROPFILES` 拖放；空队列时自动播放第一首。
  - 托盘已迁入 `core::platform::tray`，通过 `WM_APP_WAKE`
    唤醒原生主窗口：显示/隐藏、播放控制、音量、随机/循环、桌面歌词/锁定开关、退出。
- **原生外壳**：标准标题栏 Win32 窗口 + 消息循环，per-monitor v2 DPI
  （`WM_DPICHANGED`）；侧栏导航、虚拟列表、播放条、Now Playing、逐字 KTV。
- **曲库**：SQLite 索引 + 目录监听、原生搜索框/排序/整页分页列表、
  添加/移除目录、重新扫描（扫描中同一按钮变为“取消索引”；索引始终与当前
  目录列表一致，移除全部目录后重扫会清空旧曲库）；工具栏可
  “全部入队”（按当前搜索/排序加入整库，而非当前页）与“检查缺失”
  （结果写入页头副标题）；行右键可把曲目从索引移除（不删除文件）。
  列表、导航、按钮、播放控制与设置项都有 hover/pressed 样式。
- **设置页**：曲库 / 播放 / 歌词 / 独立歌词 / 桌面歌词 / 迷你 / 窗口 / 外观 /
  性能 / 系统 / 网络 / 存储 / 快捷键，内容超出时可用滚轮或右侧滚动条查看。
  播放包含无缝、交叉淡化、ReplayGain（含扫描）、10 段均衡器与睡眠定时；
  歌词/独立歌词/桌面歌词支持字号、行距、对齐、翻译、逐字填充，以及通过系统
  取色器自定义高亮、当前行、普通行、翻译行等颜色；桌面歌词与迷你播放器还提供
  背景（纯色/渐变/图片/模糊封面）、字体、圆角、阴影/描边、透明度、尺寸等
  完整外观项；所有数值项（字号、行距、透明度、宽高、EQ 增益等）可直接点击输入。
  外观包含暗/亮/跟随系统、强调色、字体、列表密度、动画帧率上限（15–120 fps）
  和纯色/模糊封面/自定义图片背景；窗口包含关闭行为、启动最小化、记住窗口位置、
  录屏与歌词捕获保护；性能包含封面加载、空闲帧率、缩略图缓存，以及桌面歌词/
  迷你播放器的 D2D 软件/硬件渲染切换（默认软件，硬件不可用时自动回退）；
  系统包含单实例、开机启动、文件关联、SMTC、通知、跳转列表，以及设置 JSON 的
  导入/导出/恢复默认（恢复默认带确认弹窗）。
- **系统集成**：单实例 + 第二实例参数转发、SMTC 媒体控制、切歌通知、
  任务栏跳转列表（最近 8 首）、关闭行为、录屏捕获保护。
- **队列**：右键上移/下移/置顶/置底；歌名/歌手/专辑/来源即时筛选；乱序播放时
  按随机顺序显示整张队列（副标题标注“乱序播放”，进入页面自动定位当前曲目）。
- **文件夹浏览**：侧栏“文件夹”页，按需读取单个目录（后台线程，最多 2 万条），
  文件夹/音频/播放列表图标区分；音频行显示 64px 封面缩略图（无封面回退图标）。
  单击进入目录或播放文件，Backspace 返回上一级，
  工具栏支持后退/前进/上一级/刷新/播放全部/加入队列，第二行地址栏可直接输入
  路径按 Enter 跳转（Esc 还原）；行右键菜单可打开/播放/导入、加入曲库、
  复制路径、在资源管理器中打开。目录读取完成通过 `WM_APP_WAKE` 唤醒 UI，暂停时也更新。
- **随机播放**：随机顺序缓存到 session；mp3list 重开时只追加新扫描到的文件，
  保留随机顺序与上次播放的曲目（曲内进度不记忆，从 0:00 开始）；
  乱序列表播完自动重新洗牌，从新一轮第一首继续。
- **封面**：当前曲目封面接入播放条/卡片/独立窗口/桌面歌词/迷你播放器，
  队列/曲库可见行显示 64px 缩略图（后台线程解码、按 key 缓存）；
  大图使用 WIC 解码期裁剪/缩放（4000×3000 封面 debug 从约 3.3s
  降到约 34ms），失败格式回退 image crate。
- **正在播放 / 歌词**：歌曲卡片 + 可滚动/可点击歌词子窗体（独立 GDI 双缓冲）、
  大歌词、独立歌词窗口、独立歌词编辑窗口（原生 EDIT + Ctrl+S）、分享图。
- **侧栏**：小窗口下导航在预留版本号区域的 viewport 内滚动，只有放不下时才
  显示细滚动条；滚轮/拖动/键盘焦点都会自动滚入视。
- **背景**：支持“纯色”“模糊封面”“自定义图片”。图片在后台线程解码（长边
  上限 2560），再一次性并行生成全窗 cover-fit 缓存；播放/切歌不逐帧解码或
  缩放。
- **桌面歌词 / 迷你播放器**：原生分层窗口已接入 `AppCore` 快照与动作；
  可锁定/穿透/置顶/调行数/字号/对齐/尺寸，帧率可独立设置（15–120 fps，
  动画期间持有 1 ms 定时器分辨率，KTV 填充按真实帧率推进），
  位置持久化；迷你播放器可单独设置
  面板/文字/强调色（卡片、悬停、弱化文字色自动派生）。不透明度 100% 即完全不透明。
- 连续切歌不再整窗重绘：按播放条/Now Playing/列表行/进度/歌词精确失效。
- GDI 双缓冲 + 脏包围盒 blit：局部重绘不闪烁；系统擦除已关闭。
- 复杂控件使用子窗体：曲库排序是原生 owner-draw LISTBOX（含悬停/滚动条）；
  滚动歌词是独立 GDI 子窗体，自己处理滚动/悬停/点击/KTV。
- 主窗口全部 **Win32 GDI 自绘**；Desktop lyrics / mini player 使用
  `WS_EX_LAYERED` 顶层窗口 + D2D DC target（默认软件光栅，可在设置里切换硬件）
  + `UpdateLayeredWindow` 脏条发布。
- 动画按时间轴驱动：每 tick 只失效当前歌词行与进度条边缘；时间文本按秒刷新；
  暂停 / 最小化 / 页面静止时停止计时器，不发生周期重绘。
- 实测（debug 构建，175% DPI，Intel 核显；历史测量，供参考）：
  - 暂停：GPU 0.00%
  - 播放 + 滚动歌词：GPU < 1%，UI 单核 CPU ≈ 4.3%
  - 桌面歌词 + 迷你播放器暂停：CPU/GPU 均 0%（事件唤醒，定时器完全停止）
  - `--bench 3`：私有约 28MB、工作集约 50MB、平均绘制约 0.61ms/帧
    （10k 队列；只 blit 脏包围盒）。
- 设置页所有数值行（歌词/桌面歌词/迷你字号、间距、透明度、网络、缓存、
  下载并发、睡眠定时等）都可点击数值直接输入；文本行编辑时光标在开头。
- 全局快捷键可自定义（默认 Ctrl+Alt+P 播放暂停、Ctrl+Alt+←/→ 切歌、
  Ctrl+Alt+M 桌面歌词、Ctrl+Alt+Q 显示/隐藏），带格式校验、重复绑定检测
  和系统占用提示；Esc 可清空某个动作（允许不绑定），托盘菜单同步显示当前
  组合，手柄可单独关闭。
- Tab 焦点环覆盖侧栏、播放条、页面工具栏、设置行和可见列表行；
  Enter/Space 激活，音量/进度支持方向键与 Home/End；主窗口、独立歌词、
  桌面歌词、迷你播放器都有 UI Automation 片段树。
- `cargo test`：237 passed / 0 failed / 6 ignored。
- `--self-test` 验证窗口与绘制；`--bench [秒]` 输出 tick/帧数、绘制耗时与私有内存。
- 测试辅助：`--page <now_playing|queue|library|folders|search|discover|smart|duplicates|stats|downloads|settings>`、
  `--folder <dir>`、`--settings-tab 0..12`、`--theme <dark|light|system>`
  （后两者只影响本次运行，不写回配置）。
