# Bamboo Music Player

Bamboo Music Player 是一个 Windows 上的原生音乐播放器，使用 Rust、egui/eframe 与 wgpu 编写。
它面向本地曲库与自建 BambooMusic 音源，提供队列、歌单、在线搜索、歌词、随机电台、下载、
音频增强和桌面歌词等功能。界面提供简体中文与英文，可在“设置 → 外观 → 界面语言”切换。

> 当前版本：0.1.0（开发中）。产物为单个 `bamboo-player.exe`，图标与默认封面已内嵌。
>
> 版本说明：本目录为 **0.1.0 egui/eframe 版**（仓库子目录 `v0.1.0-egui/`）。后续原生 Win32 + Direct2D 脏区 UI 迁移方案见
> [`docs/WIN32_UI_PLAN.md`](docs/WIN32_UI_PLAN.md)（尚未实施）；迁移时直接切换，不并行维护双 UI，也不做双 UI 对照。

## 功能概览

- **播放**：本地 mp3 / ogg / wav / flac / m4a / aac / opus；http(s) 直链与 HLS（m3u8，支持 AES-128/AES-256 整段加密分片、MPEG-TS 音频、独立音频轨、`EXT-X-GAP` 与点播流缓存）；播放/暂停、seek、
  音量/静音、随机、循环、自动下一首、退出恢复位置；默认单实例运行，第二实例打开的文件会转发给已有窗口，也可在设置中开启多实例。
- **音频增强**：无缝播放、等功率交叉淡化、10 段均衡器、ReplayGain（优先读取标签；无标签时可后台做 EBU R128 响度扫描并缓存）、0.5x–2.0x
  变速（默认保持音调，可切换磁带式）、A-B 循环、睡眠定时。
- **队列与歌单**：`.mp3list` / `.m3u` 导入导出、异步递归扫描、文件夹浏览、拖拽导入、随机顺序
  持久化、`.mp3list` 的 `#SEARCHA#` / `#SEARCH#` 语法、URL 歌单与 Bamboo 分享链接。队列页支持
  拖拽/右键调整播放顺序（上移、下移、置顶、置底），并可按歌名、歌手、专辑或来源筛选。侧栏
  “我的歌单”会记住最近打开的 24 个歌单，可一键打开/追加/重新扫描/重命名/定位；移除只影响列表，不删除文件。
- **在线音源（Bamboo 协议）**：搜索/建议/歌曲/专辑/歌手/播放地址；多音源、Cookie/请求头、
  代理、TLS、超时、重试；搜索建议防抖；在线歌词；下一首在接近曲尾时提前解析地址以参与无缝/交叉淡化。
  API/封面/缩略图复用 HTTP 连接池，并自动丢弃已被新操作取代的排队请求；缩略图只为可见行加载。设置 → 在线与网络可调 API 请求最小间隔（0–3000 ms，0=不限速）和专辑/歌手每页数量（10–200，默认 100）。
- **搜索缓存**：成功的搜索页与专辑/歌手详情页按“音源 + 类型 + 关键词/ID + 页码”写入 `cache/search.json`（最多 80 页、7 天过期）；离线时可浏览缓存结果，在线请求失败时自动回退并显示“缓存结果”徽标。
- **发现 / 随机电台**：使用本地 BambooMusic 的 `type=random&seed=...` 随机电台，自动补货，
  保留最近 8 条电台历史；发现页另有“随机漫游”推荐流（18 首，可换一批/单曲播放/全部加入），
  不依赖电台状态；智能歌单入口。
- **下载与缓存**：后台下载队列（并发数可在运行时调整）、文件名模板、同名策略、标签/封面/歌词写入；HTTP Range 断点续传（失败或取消后保留 `.part`，重试从已有字节继续）；HLS 点播下载（合并为 AAC/MP3/M4A，支持 AES-128/AES-256 与 MPEG-TS，直播流会提示不支持）；HTTP Range 流缓存
  与 LRU 清理；设置 → 缓存 可启用/关闭在线与 HLS 点播缓存、查看占用并一键清理流/封面/歌词/响度/指纹缓存（不会删除已下载文件）；缓存命中时在线后台刷新元信息/歌词；单曲下载可右键选择音质（128/320/FLAC）；队列右键可下载 URL/电台曲目；本地 BambooMusic 音源先完整缓存再播放；离线模式。
- **歌词**：LRC/SRT、编码自动/强制、逐字卡拉 OK、主歌词面板与右侧歌词栏、大歌词页（可指定显示器全屏）、独立歌词窗口（全屏或窗口化，F11 切换；封面 + 大字号歌词 + 播放控制，可放在另一台显示器，主窗口隐藏到托盘后仍刷新）、桌面歌词
  独立窗口、歌词编辑器（打点、增删行、整体偏移、撤销/重做、保存为 LRC 并保留未修改行的逐字时间、可编辑译文并保存为 `A.zh.lrc`/`A.en.lrc`/`A.jp.lrc`）、1200×1600 歌词分享图（含行内翻译）。大屏/独立窗口可单独设置字体、字号、行距、颜色、译文、逐字高亮、封面/曲目信息/进度条显示；可预取下一首本地歌词。
- **桌面增强**：托盘、迷你播放器（拖动进度、滚轮音量、静音）、Windows 系统媒体控制（SMTC，含封面/时间轴/拖动 seek）、系统通知、
  开机启动、文件关联、任务栏跳转列表（快捷任务 + 最近播放）、命令面板、音频可视化、界面缩放、
  GPU 模糊封面/流动渐变背景、Mica（可用时）、主窗口/独立歌词窗口可分别启用录屏捕获保护；桌面歌词支持全透明背景、独立边框开关、自定义文字描边/阴影颜色与厚度，并可把描边/阴影同样应用到译文和歌名/歌手页脚。
- **性能**：设置 → 性能可调动画/界面帧率（15–120 fps），统一影响逐字高亮、歌词滚动、桌面/独立歌词、可视化、背景动画与迷你播放器；曲库再次索引会跳过未变化文件并并行解析标签。
- **曲库**：SQLite 索引（可中途取消）、搜索/排序/分页、统计、智能歌单、查重与缺失文件检查；查重可选“标题+歌手+时长 / 同一路径 / 音频指纹”。设置 → 曲库 可配置启动时扫描、目录自动监听、符号链接与音频扩展名；监听触发时只重新解析变化的文件。
- **无障碍与语言**：界面缩放 0.75–1.60x；Windows 屏幕阅读器（AccessKit/UI Automation）可读取并激活主要控件与歌词行；Tab 焦点可见，进度/音量条可用方向键与 Home/End 调整。简体中文 / English 可随时切换，主界面、设置、菜单、托盘、统计与状态文本均已翻译。

## 系统要求

- Windows 10 / 11 x64。
- 支持 DX12、Vulkan 或 OpenGL 的显卡。低内存或旧显卡可在“设置 → 外观 → 渲染后端”切换到
  OpenGL（需重启）。
- 从源码构建需要 Rust 1.85+（edition 2024）与 MSVC 工具链。

## 构建与运行

```powershell
# 调试构建
cargo build
cargo run

# 发布构建（可选）
cargo build --release
# 产物：target\release\bamboo-player.exe
```

### 测试

```powershell
cargo test
```

默认测试不访问网络。需要本地 Bamboo 站点或公网音频时可手动运行联网测试：

```powershell
cargo test live_local_bamboo -- --ignored --nocapture
cargo test live_local_random_station -- --ignored --nocapture
cargo test live_http_stream -- --ignored --nocapture
cargo test live_http_stream_cache_completes -- --ignored --nocapture
```

## 打包

```powershell
# 构建 release 并把 exe + README 打成 zip（dist\）
.\scripts\package.ps1

# 便携版：额外放入 portable.txt，数据写到 exe 所在目录
.\scripts\package.ps1 -Portable

.\scripts\package.ps1 -SkipBuild
```

## 数据目录

默认使用 `%APPDATA%\BambooMusicPlayer`：

```
settings.json        设置
session.json         队列、播放位置、电台历史等会话状态
library.db           SQLite 曲库索引
logs\bamboo.log.*    按日期滚动的日志
cache\               封面、歌词与流缓存
```

在 exe 同目录放置空的 `portable.txt` 即进入便携模式，所有数据写入 exe 所在目录。
默认只允许一个实例；设置 → 窗口与系统 → “允许多个实例同时运行”可开启多窗口（重启生效，共享数据文件）。
单实例互斥体可通过环境变量 `BAMBOO_INSTANCE` 覆盖，便于同时运行多份配置。

## 首次配置本地 BambooMusic

1. 打开“设置 → 在线与网络”。
2. 在“本地曲库”音源中填写站点地址，例如 `http://127.0.0.1/musicnew/apis/local`，
   脚本名通常为 `local.php`。
3. 点击“测试连接”。返回歌曲数量即表示配置成功。
4. “在线搜索”可搜索本地曲库；“发现”页可开启随机电台。

音源地址指向 `apis/<source>` 目录即可，播放器会自动拼接 `?type=...&value=...` 请求。
本地 API 的 `info` 响应中的 `data.lrc` 会作为在线歌词显示；`type=random` 的 `seed` 参数用于
随机电台的不同批次。

## 歌词编辑器

在“正在播放”页的歌词卡片、右侧歌词栏或大歌词页点击“编辑”进入：

- 左侧选择行，右侧修改时间与文本。
- “打点”把当前播放位置写入选中行；可从任意行“跳到此句”或“从此播放”。
- 支持添加/删除行、上下移动、按时间排序、整体偏移，以及把纯文本转换为时间轴。
- 保存优先写回原 `.lrc`；没有同名歌词时保存到音频旁的 `<歌曲名>.lrc`，在线歌词首次保存会
  询问路径。未修改文本的行会保留增强型 LRC 的逐字时间；修改过文本的行回退普通 LRC。
- 行内翻译可直接编辑。基础文件保存原文，译文保存为同名的语言文件：`A.zh.lrc`、`A.en.lrc`、
  `A.jp.lrc`（设置 → 歌词 → 译文语言可选自动/中文/English/日本語）。读取时优先使用所选语言，
  缺失时回退到其他可用译文；SRT 同一时间块的第 2 行及以后按译文合并显示。

## 已知限制

- 交叉淡化/无缝播放对本地文件、可直接打开的 URL，以及已提前解析完成的 Bamboo 在线下一首生效；
  Bamboo 下一首仅在当前曲目剩余约 35 秒时开始预解析，失败按 10/30/60 秒退避；若预解析未在曲目结束前完成，仍会回退到普通“播放结束 → 下一首”路径。
- 变速默认使用 WSOLA 时间伸缩保持音调，CPU 占用略高于磁带式；极端速度下可能出现轻微重复/金属感。
- ReplayGain 优先读取文件标签；无标签时可在后台做 EBU R128 响度扫描（默认开启），结果按文件缓存。
  首次扫描需要解码整首，扫描完成前按无增益播放。
- 流缓存仅在完整播放到 EOF 后发布为正式缓存；中途停止会丢弃 `.part`。设置 → 缓存 可关闭在线/点播缓存、限制大小、查看占用并一键清理所有缓存（不会删除已下载文件）；自定义缓存目录必须为空或只含播放器缓存文件，且不能位于应用数据目录内。缓存命中后按每曲 10 分钟 TTL 在线后台刷新元信息，并在本地没有歌词时补入在线 LRC；离线时使用缓存旁已有的歌词。“正在播放”歌词卡片新增“刷新”，可强制重读本地标签或在线 `info`/歌词（忽略 TTL）。
- 下载并发数（1–4）可在设置中运行时调整；正在下载的任务不中断，已排队任务按新上限继续。直链下载中断后会保留 `.part` 和验证信息，点击“重试”时用 HTTP Range 从已有字节继续；服务器不支持 Range 或文件已变化时会自动从头开始。HLS 分片下载不支持断点续传。曲库 → 下载提供“清理未完成分片”，可递归删除下载目录中的 `.part`/`.part.meta`。
- 本地 PHP 服务若只允许单并发，长时间音频流可能占满工作进程，导致同时进行的 API 请求超时。
  播放器对本地 BambooMusic 音源会先完整下载到流缓存再播放，并优先复用已完成的缓存；下载失败时回退到
  流式播放。在线解析有超时保护。仍建议本地站点使用多进程/多线程部署。播放器会复用 API/封面 HTTP 连接池，并丢弃已被新搜索、翻页或切歌取代的排队请求；搜索结果缩略图只为可见行加载。API 请求间隔设置只限制搜索/建议/详情/解析/info/随机等 API 调用，不影响音频流和下载。
- 网络电台支持 http(s) 直链与 HLS（m3u8）。HLS 支持 AAC/ADTS、MP3 基本流分片、MPEG-TS 音频（AAC/MP3，PAT/PMT 可跨包）、`EXT-X-BYTERANGE`、带 `EXT-X-MAP` 的分片 MP4、主列表独立音频轨（`EXT-X-MEDIA`）、`EXT-X-GAP`，以及 `EXT-X-KEY` 的 AES-128/AES-256 整段加密（自动下载密钥并按 media sequence 生成默认 IV）。带 `#EXT-X-ENDLIST` 的点播流可下载为 AAC/MP3/M4A，完整播放后也会写入流缓存供下次本地打开；直播流不能下载、不能拖动进度、不写流缓存。SAMPLE-AES/SAMPLE-AES-CTR 等采样级加密与 DRM 密钥格式仍会提示不支持；MPEG-TS 中的 AC-3/E-AC-3/LATM 会给出明确错误而不是静音。
- 发现页“随机漫游”依赖本地 BambooMusic 的 `type=random&seed=...`；音源不支持 seed 时批次可能重复，队列会去重。推荐流不会自动开始播放，也不会停止正在运行的随机电台。可在“设置 → 功能开关”关闭“随机漫游推荐”。
- SMTC 时间轴约每 250 ms 上报一次；异步封面到达时会刷新浮层缩略图。
- 双语界面已覆盖静态界面文案、设置选项、菜单/托盘、统计、状态/提示文本，以及 API、音频、下载、曲库、歌词模块中的静态与格式化错误文本；用户自定义音源/歌曲/歌单名称仍按原样显示。切换语言后，已加入队列的曲目来源徽标等少量缓存文本可能要到下次载入才更新。屏幕阅读器已接入 Windows UI Automation，自定义控件带标签；歌词行、桌面歌词与迷你播放器整窗可被读出，自绘滑杆支持方向键与 Home/End。聚焦控件时 Space 由控件激活，不会触发全局播放/暂停。
- 跳转列表依赖 Windows 将 exe/AUMID 关联到任务栏按钮；未安装开始菜单快捷方式时，部分系统可能不显示自定义分类。最近文件只收录本地曲目（最多 8 条）。
- 播放器未运行时点击跳转列表的“播放/暂停/下一首”会启动播放器并在首帧执行该命令（需要已保存的队列/会话）。
- 多实例模式共享设置、会话、曲库和缓存，会话/设置最后写入者生效；该模式下跳转列表自动停用，日志按 PID 分文件。
- 目录自动监听依赖系统文件通知；网络共享、部分虚拟盘或不支持通知的文件系统可能收不到事件，此时可手动“更新索引”。增量监听不处理文件内容以外的时间戳变化（如权限变更）。
- 曲库索引可手动“更新索引”，也可在设置 → 曲库开启“启动时扫描”和“目录自动监听”；自动监听使用系统文件通知，只重新解析新增/修改的文件并移除已删除文件的索引行。手动索引可中途取消并保留已写入的行。再次索引会跳过 size+mtime 未变化的文件，其余文件按批并行读取标签并事务写入；首次全量解析仍取决于磁盘/CPU 速度。
- 查重可选“标题+歌手+时长 / 同一路径 / 音频指纹”。指纹模式使用轻量 landmark 哈希（非 Chromaprint），
  首次扫描需要解码全库并写入 SQLite 缓存，耗时较长；极端再编码可能漏判。移除只删索引行，不删除文件。
- 侧栏 Logo 固定在顶部，只有导航/歌单/导入按钮区域滚动；底部版本文字保留额外下方空白。侧栏“我的歌单”最多保留最近 24 个歌单路径；单击打开会替换当前队列，右键可改为追加、重新扫描、重命名或从列表移除。重命名只修改磁盘文件名并同步当前路径；移除只影响列表，不会删除磁盘文件；缺失文件状态每 10 秒检查一次。
- 队列排序在随机模式下只调整播放顺序（`shuffle_order`），不改变底层队列与当前曲目；顺序模式下会重排底层列表但保持当前曲目不变。筛选状态下“上移/下移”按可见行移动。
- 歌词编辑器的行内翻译可编辑；原文与译文分别写入基础 LRC/SRT 和 `A.<language>.lrc`。清空译文后保存会删除该编辑器管理的译文文件。未修改文本的行会保留逐字时间。
- 独立歌词窗口默认无边框全屏，按 F11 或右上角按钮切换窗口化，窗口化时可拖动顶部区域；模式与打开状态写入会话。可在“设置 → 窗口与系统”选择显示器，窗口内可用 Space 播放/暂停、方向键跳转、Esc 关闭。它使用 deferred viewport，主窗口隐藏到托盘/最小化后仍会刷新（按设置帧率，默认 60 fps，位置按经过时间插值）。大屏/独立窗口的字体、字号、行距、颜色、译文/逐字开关、封面/曲目信息/进度条可在“设置 → 歌词 → 大屏 / 独立歌词窗口”单独配置。
- 歌词分享图固定 1200×1600，取选中行附近 5 行歌词，包含行内翻译；超长行省略，不包含逐字时间。
- 桌面歌词逐字高亮按字符裁剪；普通 LRC 需要开启“逐字高亮”才会有按比例填充。背景“透明”不绘制面板/边框，不透明度可调到 0；边框开关独立于文字阴影，描边/阴影的颜色、厚度/距离可分别设置，并可选择同样作用于译文和页脚。
- 动画/界面帧率（15–120 fps）在设置 → 性能中调整；低帧率更省电，但逐字高亮和滚动会相应变粗。系统在窗口最小化/被遮挡时仍可能进一步节流。
